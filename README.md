Project Title: NYC Subway Delay Analysis (2020–2026)

Problem Statement:
NYC subway delays affect millions of commuters daily. This project analyzes historical delay data to identify trends over time, key delay categories, and operational differences across divisions.

Data Source:
MTA Subway Trains Delayed dataset (NY Open Data)

Tools Used:
Power BI
Power Query (data cleaning)
Excel 

Analysis Performed:
Monthly trend analysis of subway delays
Distribution of delays by reporting category
Division-wise comparison of delay severity

Key Insights:
Subway delays show clear temporal patterns across months
Certain reporting categories contribute disproportionately to total delays
Some divisions experience higher operational disruption than others
